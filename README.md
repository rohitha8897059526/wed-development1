HTML & CSS Mini Website Collection
A collection of beginner-friendly website projects developed using
HTML5 and CSS3. This project demonstrates the fundamentals of
front-end web development through three separate webpages: a food
ordering website, a Taj Mahal tourist information page, and a restaurant
menu page.
1. Project Title
HTML & CSS Mini Website Collection

Main Project: Foodie -- Food Ordering Website
2. Project Description
The HTML & CSS Mini Website Collection is a beginner-level front-end web
development project created to demonstrate the basic concepts of HTML
and CSS.

The project contains three independent webpages:
- Foodie: A food ordering website that displays restaurant
  information, food categories, menu items, prices, special offers,
  and customer reviews.
- Taj Mahal: A tourist information webpage that provides details
  about the Taj Mahal, places to visit, activities, and food
  suggestions.
- My Restaurant: A restaurant menu webpage that organizes food
  items into starters, main course, and desserts.
These webpages use HTML elements such as headings, paragraphs, lists,
images, navigation links, and sections. CSS is used to improve their
appearance through colors, fonts, spacing, borders, and layouts.

The three webpages are standalone examples and are not connected as one
multi-page application.
3. Project Objectives
- To understand the fundamentals of HTML5.
- To learn how to create and structure webpages.
- To apply CSS3 for webpage styling and design.
- To organize webpage content using headings, sections, lists, and
  containers.
- To present food menus and tourist information in a readable format.
- To understand the use of images and navigation links.
- To practice basic responsive web design using CSS media queries.

File: rohitha.html
- Restaurant welcome message.

- Food image element.

File: abcd.css
- Page background, typography, text alignment, and colors.
- Card styling with borders, rounded corners, and shadows.
- Image sizing and object-fit.
- A media query for screens up to 480 pixels wide.

8. Installation Steps
No package installation or build process is required.
1. Download or clone the project repository.
2. Extract the files, if downloaded as a ZIP archive.
3. Keep all HTML and CSS files in one project folder.
4. Keep abcd.html and abcd.css in the same folder.
5. Add the required local images (1.jpg and naveen.jpg) or update
   their paths.
6. Open the project folder in a code editor such as Visual Studio Code.
Clone the repository:
git clone <your-github-repository-url>
cd html-css-mini-websites
9. How to Run the Project
Method 1: Open directly in a browser
- Open abcd.html to view the Foodie webpage.
- Open akka.html to view the Taj Mahal webpage.
- Open rohitha.html to view the restaurant menu webpage.
Method 2: Use Python's local static server
From the project folder, run:
python -m http.server 8000
Then visit:
http://localhost:8000/
Select the HTML file you want to view. Stop the server with Ctrl+C.
